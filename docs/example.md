# Заметки по проекту

Jot показывает markdown **как документ**, но оставляет его *текстом*: разметка приглушена и проявляется на строке с курсором. Код — `моноширинным`, ссылки — [подчёркнуты](https://github.com/Stasyao37), важное — ==выделено==.

## На этой неделе

- [x] каркас и тема из Shelf
- [x] живая подсветка разметки
- [ ] вкладки и восстановление сессии
- [ ] панель папки с заметками

> Писать удобнее, когда ничего не мешает:
> одна колонка текста и стекло вокруг.

### Сборка

```sh
cmake -B build -G Ninja && cmake --build build
```

| Приложение | Что это     |
|------------|-------------|
| Jot        | заметки, md |
| Shelf      | проводник   |
